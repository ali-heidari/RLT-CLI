# Code of Conduct

## The short version

Be decent. Assume the other person is trying to help.

## What is expected

- Treat people with respect, including when you think they are wrong.
- Critique the code, not the person who wrote it. "This drops errors on the
  floor" is useful; "this is amateur work" is not.
- Accept that other people have context you do not, and ask before assuming.
- Take responsibility for mistakes and fix them. Everyone ships bugs; this
  repository's own history is a list of them.

## What is not

- Harassment, insults, or personal attacks.
- Sexualised language or imagery, and unwelcome attention of any kind.
- Publishing anyone's private information without their permission.
- Sustained disruption of discussions or review.

## Scope

This applies in the repository — issues, pull requests, code review, commit
messages — and anywhere someone is representing the project.

## Reporting

Report a problem by email to the address on the maintainer's GitHub profile.
Reports are handled privately. If the report concerns the maintainer, and you
would rather not send it there, say so publicly in whatever way you judge safe;
a project this small has no separate escalation path to offer, and pretending
otherwise would be dishonest.

The maintainer may remove comments, commits, issues and pull requests that
breach this document, and may ban repeat offenders from the repository.
